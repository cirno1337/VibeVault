The token is stored only in this browser profile (extension storage) and is sent only to the URL above. Use an ingest token, never the admin token.

Part of every event's identity: keep it stable for this browser profile (copy it back after a reinstall).

Collection

Excluded conversations

Excluded conversations are never read beyond their id. Excluding one also drops anything of it still queued here; to delete what was already sent, delete the session in VibeVault (needs the admin token).

    What this extension reads and sends

    • Reads: the visible text of user and assistant messages in the conversation open in the current tab on claude.ai and chatgpt.com, the conversation URL/id/title, and message order.
    • Never reads: cookies, site storage, auth headers, hidden app state, other tabs or sites, the prompt box draft, uploaded file contents (shown as placeholders), account or profile data.
    • Sends: only while collection is on for the site and the conversation is not excluded; after a response finishes streaming, in batches, to the VibeVault URL above and nowhere else.
    • Redacts likely secrets (API keys, tokens, private keys, passwords in assignments) before anything is queued. This is best-effort pattern matching; the server scans again.
    • Private windows are off by default. When the sites change their layout, the extension stops collecting and the popup says "adapter outdated" instead of guessing.
